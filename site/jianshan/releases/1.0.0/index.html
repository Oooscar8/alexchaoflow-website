准备版本 · 尚无公开下载

这个版本正在准备发行，尚未通过 TestFlight 公开分发，也尚未在 App Store 上架。这里的版本记录用于说明当前准备中的功能，不代表 App 已可安装。正式上线后，下载入口将提供真实的 Apple 官方链接。

构建 4 的更新

参考汇率来源固定为欧洲央行（ECB）的每日欧元参考汇率，由 Frankfurter 提供并换算为人民币基准。见山再取倒数，显示每单位外币对应的人民币；这些是账本参考汇率，不是盘中实时成交价。USDT、USDC 继续使用独立手动兑换率。

设置页与隐私政策同步说明汇率来源和换算方式。查询参数只包含币种代码，不发送账本内容；仍可手动维护兑换率。

保留“设置 → 使用支持与反馈”入口，可打开官网使用支持页面查看操作说明和公开支持邮箱。现有资产、消费、截图识别、备份与演示截图继续适用，App 未新增账号、自动云同步或行为追踪。

这个版本提供什么

  • 在 iPhone 与 iPad 上维护多币种资产和日常消费。
  • 记录人民币估值快照，查看资产分布与变化。
  • 选择截图，在设备上识别文字，人工核对后再保存。
  • 主动刷新 ECB 参考汇率（经 Frankfurter 提供并换算）或手动设置兑换率。
  • 导出与恢复 JSON 备份，使用快捷指令或记账链接生成待审核内容。

使用前了解

要求 iOS / iPadOS 17 及以上。当前没有银行账户连接、交易、账号或自动云同步。趋势快照不等于投资收益。导出的备份没有单独密码保护，请妥善保存。

数据与支持

本版沿用当前准备版本的设备端账本和识别方式：资产、消费与截图识别在设备上处理；主动查询参考汇率会连接 Frankfurter 的 ECB 单一来源接口。完整数据处理范围见隐私政策，使用步骤与限制见使用支持。使用或隐私问题可联系support@alexchaoflow.com。
