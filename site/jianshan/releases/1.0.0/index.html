1.0.0 (3) · 准备中

准备版本 · 尚无公开下载

这个版本正在准备发行，尚未通过 TestFlight 公开分发，也尚未在 App Store 上架。这里的版本记录用于说明当前准备中的功能，不代表 App 已可安装。正式上线后，下载入口将提供真实的 Apple 官方链接。

构建 3 的更新

在 App 的“设置”中新增“使用支持与反馈”入口，打开官网的使用支持页面，方便查阅操作说明与常见问题。此入口目前提供帮助信息；公开支持联系方式仍将在正式发行前补齐。

本次准备版本沿用现有资产、消费、截图识别、汇率与备份功能。官网的功能介绍、演示截图和隐私政策继续适用；没有新增账号、数据收集或云同步。

这个版本提供什么

  • 在 iPhone 与 iPad 上维护多币种资产和日常消费。
  • 记录人民币估值快照，查看资产分布与变化。
  • 选择截图，在设备上识别文字，人工核对后再保存。
  • 主动刷新参考汇率或手动设置兑换率。
  • 导出与恢复 JSON 备份，使用快捷指令或记账链接生成待审核内容。

使用前了解

要求 iOS / iPadOS 17 及以上。当前没有银行账户连接、交易、账号或自动云同步。趋势快照不等于投资收益。导出的备份没有单独密码保护，请妥善保存。

数据与支持

本版沿用当前准备版本的设备端账本和识别方式：资产、消费与截图识别在设备上处理；主动查询参考汇率会连接外部汇率服务。完整数据处理范围见隐私政策，使用步骤与限制见使用支持。公开支持联系方式将在正式发行前补齐。

未来每次发布会同步更新本页对应的版本说明、功能介绍和分发状态。
